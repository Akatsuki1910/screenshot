インストール手順

  1. 上のボタンから zip をダウンロードして、任意の場所に展開する
  2. Chrome で chrome://extensions を開く
  3. 右上のデベロッパーモードをオンにする
  4. パッケージ化されていない拡張機能を読み込むをクリック
  5. 展開したフォルダを選択する
zip の中身がそのまま拡張機能です。展開したフォルダは読み込んだあとも削除しないでください。Chrome 109 以上が必要です。

使い方

  1. 撮影したいページを開いて、ツールバーの拡張機能アイコンをクリック
  2. 親セレクタと子セレクタを入力すると、該当する要素の件数が表示される
  3. 1 件以上あれば保存ボタンが有効になり、押すと連番の画像が保存される

非表示の要素も撮影できます。別ドメインの背景画像が空白になる場合は、詳細オプションの「別ドメインの画像も取り込む」をオンにしてください。

更新について

新しいバージョンが公開されると、拡張機能のアイコンに NEW バッジが付き、ポップアップにお知らせが出ます。その場合はここから新しい zip をダウンロードして、展開したフォルダを差し替えたうえで chrome://extensions で再読み込みしてください。

現在公開中のバージョン情報は version.json で配信しています。
